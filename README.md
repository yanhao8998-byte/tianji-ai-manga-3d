所有媒体大文件（成片、音频、关键帧图）保留在本地，不进 GitHub。

## 流水线全貌

```
A 风格化 (style_all_v2.py) → B 脸部精修 (face_refine_all.py) → C 组装 (build_episode2.py)
                          编排者 = supervisor.py（守护进程）
                    兜底 = tianji_guard.py（Windows 计划任务，每 10 分钟 + 登录时）
```

**一集的数据规模**：74 段 / 666 张关键帧 / 657 张风格化完成。

## 常用操作

### 改完东西要存版本

```bash
cd /d/天纪漫剧项目
git status                    # 看改了什么
git add -A
git commit -m "说明这次改了什么"
git push
```

### 提交信息写法

用「模块 + 动作」的格式，三个月后还能看懂：

```
风格化：v2 批次重试逻辑，失败帧自动降级
分镜表：补齐第 40-52 段的运动曲线
值守手册：更新第 3 阶段排查步骤
```

### 拉取别人的更新

```bash
git pull --rebase origin main
```

> ⚠️ 若报 `rejected, fetch first`，先 `git fetch origin main` 再 `git checkout -b main origin/main`，
> 把改动重新提交后 push。

- **默认分支 `main`**，换行符不自动转换（`core.autocrlf=false`）。
